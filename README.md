## Selected Projects

### German Electricity Market Analysis

I built this project to explore how increasing solar generation affects electricity prices in the German-Luxembourg electricity market using ENTSO-E data.

The analysis looks at intraday price patterns, negative price hours, solar capture rates, and how the relationship between solar generation and electricity prices has changed over time.

**Tools:** Python, pandas, matplotlib, Jupyter Notebook, ENTSO-E API

[View project](https://github.com/andreas-walliser/energy-market-price-analysis)

### Germany Renewables Dashboard

I built this project to get hands-on experience with a simple data pipeline and dashboard workflow using German electricity generation and day-ahead price data.

Data is collected from the Energy-Charts API with Python, stored in PostgreSQL, and explored through Grafana dashboards.

**Tools:** Python, PostgreSQL, SQL, Grafana, Docker Compose

[View project](https://github.com/andreas-walliser/germany-renewables-grafana)
